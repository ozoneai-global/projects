U.S.-BASED BIOTECH / FOOD-SAFETY LAB COMPANY
Computer Vision · PyTorch · FastAPI

Automated Microbial Colony Detection & Classification

01

Designed and deployed a fully automated AI system to detect, count, and classify microbial colonies from petrifilm lab samples — replacing an entire team of manual lab analysts with a GPU-accelerated ML pipeline.

Problem

Lab analysts manually counted colonies on petrifilm plates across multiple test types — Aerobic Count, Yeast & Mold, E. coli, Coliform, Enterobacteria, Lactobacillus, B. cereus, and others. Manual counts were slow, error-prone, and fundamentally limited in throughput.

Solution

Trained Vision Transformers combined with CLIP embedding models and custom PyTorch classifiers to accurately count colonies and handle edge cases like TNTC (Too Numerous To Count) plates. A mechanical imaging bot captures petrifilm images and sends them to the ML system via a FastAPI endpoint, returning structured colony count reports in real time.

Impact

  • Accuracy: 90–100% across all petrifilm types
  • Throughput: 10,000+ samples/day vs. <1,000 manually
  • Infrastructure cost: <$200/month on AWS GPU — vs. a 20-person analyst team
  • Zero marginal cost at higher volumes — scales horizontally

Stack

Vision Transformers, CLIP, PyTorch, FastAPI, AWS GPU instances

LLM · NL-to-SQL · Data Analytics

Natural Language Analytics Platform for Internal Teams

02

Built a chat-based analytics system that lets non-technical teams — operations, sales, customer support, and analysts — query live databases and generate visualisations using plain English, with no SQL or coding required.

Problem

Business teams were dependent on developers or analysts to pull data from MongoDB and MySQL databases. Reporting cycles were slow, and teams lacked real-time visibility into their own operational metrics.

Solution

Integrated the Claude LLM API to accept natural language queries, generate corresponding Python code and database queries, and execute them in a secure sandbox environment connected to production databases. Results — including interactive Plotly charts, tables, and JSON outputs — are rendered directly in the UI for users to explore and export.

Impact

  • Any team member can self-serve data queries — no SQL knowledge needed
  • Eliminated bottleneck of routing every data request through engineering
  • Exports (charts, tables) plug directly into reports and presentations
  • Code execution runs in an isolated sandbox — no direct DB access exposure

Stack

Claude LLM API, Python, Plotly, MongoDB, MySQL, FastAPI, sandboxed execution environment

Document AI · LLM · Data Automation

Automated Lab Result Extraction & Unit Normalisation

03

Built an AI system that reads laboratory reports in any format, extracts each test and its result, validates the units, and converts values into the units each customer specifies — replacing manual data entry from lab documents entirely.

Problem

Lab reports arrived in many formats: different labs, layouts, scanned PDFs, tables, and free text. Each used its own naming and unit conventions. Analysts manually read every report, keyed results into systems, and converted units by hand to match customer requirements. The work was slow and repetitive, and a single wrong conversion could invalidate a result.

Solution

Developed a document extraction pipeline that handles any lab report layout and identifies test parameters, result values, and their reported units. A validation layer checks each unit against the expected unit for that parameter and flags mismatches or ambiguous entries. A rules-based conversion engine then normalises every value into the customer's specified units, returning structured output ready for direct system ingestion.

Impact

  • Eliminated manual data entry from lab reports entirely
  • Works across varied document formats — no per-lab templates needed
  • Automatic unit validation catches inconsistencies before downstream systems
  • Customer-specific unit conversion removes a recurring source of human error
  • Processes 1,000 reports/day at 90% field-level accuracy

Stack

OCR, LLM, Python, FastAPI

Agentic AI · LLM · Code Generation

Multi-Agent System for Automated Pricing Logic Code Generation

04

Built an agentic system that turns plain-English business pricing rules into production-ready code with unit tests. A coding agent and a QA agent collaborate iteratively, with a human reviewing the final output before deployment.

Problem

Pricing logic changes often: discounts, tiers, surcharges, customer-specific rules. Each change had to be passed from business teams to developers, interpreted, coded, and tested by hand. Requirements were often incomplete or ambiguous, leading to rework, slow turnaround, and pricing bugs reaching production.

Solution

Designed a multi-agent workflow where a user describes pricing logic in natural language. The system infers the relevant data schema and asks clarifying questions to resolve gaps before writing any code. A coding agent generates the pricing implementation; a QA agent writes unit tests and verifies the code against the confirmed requirements. A human reviews the final output before deployment.

Impact

  • Business users can specify pricing changes directly in plain English
  • Clarifying questions surface missing requirements up front, reducing rework
  • Every generated function ships with its own unit tests
  • Human review retained as the final gate before production
  • Turnaround for pricing changes cut from 5 days to minutes

Stack

Claude API, Python, pytest, FastAPI

U.S.-BASED LOGISTICS & TRADE TECH COMPANY
Document AI · NLP · Computer Vision

AI-Powered Document Data Extraction at Scale

03

Led end-to-end development of an AI service for intelligent data extraction from logistics and trade documents — processing 50,000 documents per day with high field-level accuracy across 100+ structured data points.

Problem

Logistics operations required manual extraction of structured data from high-volume, varied document types — Bills of Lading, Arrival Notices, ISFs, Invoices, Packing Lists, and Customs documents. Manual extraction was a critical bottleneck in the data ingestion pipeline.

Solution

Built a multi-model AI pipeline combining Detectron2 for document layout detection, spaCy-based NER models for entity recognition, Google T5 for structured text understanding, and GPT-4 Vision for visually complex documents. Developed a unified API layer for organisation-wide access to all AI extraction services.

Impact

  • Extracts 100+ fields per document — ETA, ETD, Consignee, Shipper, Manufacturer, Port of Lading, Country of Origin, Invoice Number, and more
  • Processes 50,000 documents/day in production
  • Data ingestion pipeline latency reduced by 75%
  • Single unified API layer maintained across the organisation

Stack

Detectron2, spaCy, Google T5, GPT-4 Vision, Python, FastAPI

INDIA-BASED C.A FIRM
PII Redaction · OCR · Compliance

Automated PII Redaction System (DPDPA Compliant)

04

Built a document redaction application for CA firms and banking clients to automatically detect and redact personally identifiable information in compliance with India's Digital Personal Data Protection Act (DPDPA).

Problem

CA firms and banks handle large volumes of sensitive client documents containing PAN, Aadhaar, bank account details, GST numbers, signatures, and photographs. Manual redaction before sharing documents was time-consuming and prone to missed fields.

Solution

Built a FastAPI-backed web application where users upload documents processed through an OCR pipeline followed by AI-based PII detection using Microsoft Presidio — an open-source framework for detecting, masking, and anonymising sensitive data across text, images, and structured data. Supports custom keyword-based redaction rules, document splitting, and merging.

Impact

  • Fully automated redaction of PAN, Aadhaar, bank info, GST, photos, and signatures
  • DPDPA-aligned workflow with audit-ready outputs
  • Custom keyword rules allow clients to extend redaction beyond standard PII
  • Non-technical users can operate the entire workflow via a simple UI

Stack

FastAPI, Microsoft Presidio, OCR, Python, HTML/CSS
